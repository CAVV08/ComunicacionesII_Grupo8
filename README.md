## Resumen del Proyecto
Este proyecto presenta la implementación y validación de un enlace digital en GNU Radio utilizando hardware SDR HackRF One. Debido a la disponibilidad de recursos, se realizó un montaje colaborativo empleando 16-QAM a 960 MHz. Se documenta la arquitectura del receptor, la adaptación de tasa, la sincronización de portadora y los resultados experimentales, destacando una constelación recuperada con un EVM del 19.3% y una BER del 2.1% validada mediante CRC=OK.

## Parámetros Principales
* **Modulación:** 16-QAM
* **Frecuencia Central:** 960 MHz
* **Tasa de Símbolos (Rs):** 8 ksym/s
* **Tasa de Bits (Rb):** 32 kbps
* **Tasa de Muestreo del SDR:** 2 Msps
* **BER Medida:** ~2.1%
